I'm **Deepankar Chakroborty**, but almost everyone calls me **Deep**.

I'm a postdoctoral scientist in Research Oncology at **Genentech**, working at the intersection of cancer biology, functional genomics, and computation. Before that, I earned my PhD in Medical Biochemistry and Genetics at the **University of Turku, Finland** 🇫🇮.

My favorite projects start with a biological question, pass through a cell-culture hood, and end somewhere inside RStudio or a terminal window. Sometimes the order changes. 🔄

- 🧬 I study cancer using functional genetics, single-cell RNA-seq, and epigenomics.
- 🧫 I generate experimental data at the bench and write the code that helps me make sense of it.
- 📊 I rely heavily on **R**, **Python**, and shell scripts.
- ⚙️ I enjoy benchmarking and optimizing code–occasionally far beyond what the original problem deserved.
- 🦀 I am slowly learning Rust. The borrow checker and I are negotiating.
- 🍎 I enjoy making macOS behave like a proper Unix machine.
- 🐧 Debian is, of course, always welcome.

## 🔬 Science that escaped the notebook

| Project | What it does |
|---|---|
| **[DORM](https://eleniuslabtools.utu.fi/main/docs/DORM.html)** | An open-source R/Shiny resource for exploring recurrent cancer mutations while reducing common biases in public mutation data. Try [Mutations](https://eleniuslabtools.utu.fi/tools/DORM/Mutations/) or [Residues](https://eleniuslabtools.utu.fi/tools/DORM/Residues/); browse the code in [DORM_Mutations](https://github.com/dchakro/DORM_Mutations) and [DORM_Residues](https://github.com/dchakro/DORM_Residues). |
| **[iSCREAM](https://doi.org/10.1074/jbc.RA118.006336)** | A functional-genetics platform I developed during my PhD for screening activating cancer-associated mutations—equal parts mutagenesis, cell biology, sequencing, R, and stubbornness. |
| **[Mutation Designer](https://eleniuslabtools.utu.fi/main/MutationDesigner.html)** | An R/Shiny app that automates primer design for whole-plasmid site-directed mutagenesis. Because repeatedly consulting a codon table builds character—but automation builds primers. |

## 🛠️ Tiny tools for disproportionately annoying problems

| Repository                                                            | The itch it scratches                                                                                                                         |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **[alacritty_colors](https://github.com/dchakro/alacritty_colors)**  | Apply color schemes to the Alacritty terminal emulator. A terminal should work well *and* look good. 🌈                                       |
| **[brewlog](https://github.com/dchakro/brewlog)**                     | Run Homebrew commands while logging everything to a file. Future-you would needs the receipts. 🍺                                             |
| **[PiHoleOnMacOS](https://github.com/dchakro/PiHoleOnMacOS)**         | My archived workflow for running Pi-hole inside Docker on macOS Mojave. An artifact from a time when you could block Ads on the internet. 🕳️ |
| **[MacOS-DNS-changer](https://github.com/dchakro/MacOS-DNS-changer)** | Change the DNS servers used by the macOS Wi-Fi/USB-ethernet interface from a shell script.                                                    |
| **[ggplot_themes](https://github.com/dchakro/ggplot_themes)**        | Themes for making publication-quality figures with ggplot2. 📈                                                                                |
| **[shared_Rscripts](https://github.com/dchakro/shared_Rscripts)**    | Reusable R functions collected under one roof so I can stop copying them between projects.                                                    |
| **[benchmarkR](https://github.com/dchakro/benchmarkR)**               | R performance experiments and my lovingly over-analyzed [tips and tricks](https://github.com/dchakro/benchmarkR/raw/master/results.pdf). 🏎️  |
